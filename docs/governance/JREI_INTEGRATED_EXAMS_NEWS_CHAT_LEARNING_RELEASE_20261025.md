## Copyright, source permissions and originals
Public web access does not automatically confer rights to reproduce entire proprietary tests inside a paid exam. Source metadata/subject patterns can be discovered without asserting republication rights; permitted private copies only after applicable source/access/license review. Third-party institutional tests from Gaj, Kanoon, Gozine2, Parseh and other providers require per-provider/source review. **Gozine2's own public official channel expressly prohibits reproduction/distribution of its test questions even with attribution.** Never present unauthorized copies under a JREI licence. Create new independent questions from curriculum constructs and independently verify they are not lightly paraphrased protected questions. Release only authored/licensed material. This is compatible with the owner's no-file-sale, paid-examination business model.
