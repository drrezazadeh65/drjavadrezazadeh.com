## 9. Evidence and release protocol
- Engineering stages: A source reconciliation; B complete signed transport+safe schema; C operational source/OCR/knowledge+news; D real bilingual AI tool orchestration; E reviewed examination+payments; F runtime/resilience/privacy and independent scientific evaluation; G CI/browser/SQL/exam/SEO/security final acceptance; H one owner-directed guarded Bertina deploy with exact immutable SHA and post-deploy live evidence.
- Each atomic obligation is tracked with actual source, test artifact, host activation evidence, missing external decision (when relevant) and explicit PASS/FAIL/UNKNOWN. Inability to access private host is UNKNOWN, not automatically FAIL or PASS.
- No additional instructions or live operator inputs should be demanded merely to repeat already observed setup; never reset Node A/B private keys, install alternate runtimes, create parallel databases, or restart from scratch.
- A scope may only be called CLOSED after its functional, security, science, live and rollback acceptance appropriate to that scope. Await actual publication only after all release gates for the selected release are green. Public AI/exams remain OFF until separately validated.
