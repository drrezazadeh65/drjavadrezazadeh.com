- Each JREI AI obligation (not all 117 website atoms) is tracked with actual source, test artifact, host activation evidence, missing external decision (when relevant) and explicit PASS/FAIL/UNKNOWN. Inability to access private host is UNKNOWN, not automatically FAIL or PASS.
- No additional instructions or live operator inputs should be demanded merely to repeat already observed setup; never reset Node A/B private keys, install alternate runtimes, create parallel databases, or restart from scratch.
- A scope may only be called CLOSED after its functional, security, science, live and rollback acceptance appropriate to that scope. Await actual publication only after the JREI AI release gates and essential cross-site nonregression gates are green; unrelated website 117 completion is not a prerequisite for the AI code-only release, and a code-only release is not public AI activation. Public AI/exams remain OFF until separately validated.
