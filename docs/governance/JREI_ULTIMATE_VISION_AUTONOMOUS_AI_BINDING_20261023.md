## Autonomous operation safety contract

- Routine actions may be autonomous **only within explicitly approved scoped policy**: source domains/licences and budgets, schedules, storage and network, model provider/credential access and cost limits, learner consent, exam rights and account access. Missing permission fails closed.
- Distinguish deterministic code, integrated but disabled connectors, configured and running services, verified observed outcomes and independently validated research. Database DDL or a model adapter does NOT qualify as a running AI engine.
- Never assume a ChatGPT Plus subscription includes OpenAI API billing. Cloud APIs require distinct approved credentials and billing; keep keys only server-side, outside version control and public JavaScript.
- All self-improvement proposals require isolated branches, a diff, reproduction evidence, security/privacy review, final-stage approved evaluation and human-reviewed pull requests. No unrestricted code execution, uncontrolled retraining, security/payment modifications or automatic deployment.
- The user's implementation-only pause on testing and rollout remains binding. New capabilities must be recorded SOURCE/PARTIAL/GATED, never PASS until authentic observed acceptance.
