## Technical invariants

1. **API provider:** OpenAI API (or any cloud provider) is an independently billed credential; ChatGPT user subscriptions do not authenticate an automated website. Keep provider secrets only in private Bertina environment. Fixed HTTPS provider endpoints, verified TLS, narrow approved model allowlist, outbound byte/time/request quotas, provider budget controls. No user-supplied remote URLs, open proxy or client-provided model ID.
2. **Evidence:** source is independently reviewed with legally permitted use and fresh version/digest; citation identifies original source. Model-generated text is provisional; independent scientific claims must be verified. No invented answers, admission odds, psychological diagnosis or certified TESTLY/Humanability scales.
3. **Personalisation:** public conversational defaults **do not store user chat or read learner records**. Optional account memory requires clearly scoped current consent, parental/guardian permissions as relevant, minimum retention and separate owner-controlled lifecycle.
4. **Tool boundary:** only explicitly registered, read-only, privacy-scoped tools may be called by a model coordinator. Any payment, consent, rights, scores, source publication or release actions require original deterministic verified server-authority flows.
5. **Autonomous coding:** propose isolated feature-branch patches/PRs with owner review and rollback; never autonomously merge, push to canonical branch, deploy, migrate production, invoke unrestricted commands or modify credentials/payment/security.
6. **Final approval:** source completion followed by ONE consolidated integrative acceptance: actual paid API/inference, network safety, GDPR/guardian checks, licensed acquisition and extraction, source/answer quality, scientifically reviewed test, original financial settlement, offline Windows handling, load/resource/budget/latency measurements, mobile accessibility, SEO, end-to-end provenance and rollback. Only owner authorises deployment.

- **SOURCE**: actual source file committed but not verified.
- **GATED**: dependent permissions, approved provider credentials/budget, licences, acceptance or migration missing.

- **BLOCKED**: fail-closed, current static fallback preserved.
- **NOT RUN**: no intermediate tests, crawls, paid API calls, migrations, deployment or model run.
