## Evidence categories that must never be conflated

1. **Rendering/interaction validity:** browser tests prove that form steps and UI components behave as specified under tested conditions, not that a psychological or educational outcome is measured correctly.
2. **Structural/security validity:** MySQL/MariaDB synthetic fixtures, MFA/age/consent policy and no-storage tests demonstrate limited software compatibility, not that live Bertina identities, guardians or actual evidence were independently verified.
3. **Scientific validity:** requires actual ethics, qualified investigators, participant data where necessary, appropriateness to purpose, independent review, replicability and fairness evidence. None is manufactured by documentation, design, code, CI or user direction.
