# JREI Academic — website client preview

Public website design only. All AI engines, inference, research memory, orchestration, and private data remain on the separately managed JREI infrastructure. No engine source, owner credentials, or private research data are included.

- Website source: `fa/jrei-academic/index.html`.
- Proposed integration contract: `docs/jrei-academic/api-contract.json`.
- Original preview: 16 tool views, landing page, dashboard, projects, library, pricing, guest entry, local history, settings, help, privacy, research ethics, terms, about and contact.
- Four deterministic local sample tools: descriptive statistics, DOI pattern extraction (not verification), word frequency, simple comparison. Scientific search links are external navigation, not live JREI research.
- No live AI, file upload, authentication, subscriptions or payment in this preview. Local browser storage is for non-sensitive sample data only; clear/export from Settings.
- Keep noindex until owner-approved publication. Preserve all existing public routes and the existing manual deploy process.
- The API contract is a proposed interface only. Map aliases to actual verified JREI capabilities later. Use server-side tenant authorization, strict allowlists, existing site account/commerce infrastructure where appropriate, scoped worker identity, quotas, idempotency, audit and controlled asynchronous jobs. No public model or private owner endpoints.
- Before launch: integrated visual/accessibility, mobile, security, data isolation, capacity, actual JREI results, payment and deployment acceptance. Do not claim verified production service before evidence.
