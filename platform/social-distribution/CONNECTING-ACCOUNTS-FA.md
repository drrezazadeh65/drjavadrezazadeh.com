# راهنمای اتصال امن حساب‌ها و آزمایش انتشار — AWOSE

تاریخ: ۱۱ اکتبر ۲۰۲۶ | مرحله: طراحی اجرایی + نسخه اول آزمایشی، بدون انتشار واقعی.

## اصل اتصال

داشبورد هیچ‌گاه رمز عبور اصلی اینستاگرام، فیس‌بوک، ایکس، گوگل، لینکدین یا واتس‌اپ را نمی‌گیرد. برای سرویس‌های OAuth، کاربر در صفحه رسمی سرویس مجوز می‌دهد. تبادل کد و توکن باید فقط در سرور محافظت‌شده، با نشست مدیر، CSRF state، PKCE در صورت نیاز، حداقل مجوز و توکن رمزگذاری‌شده انجام شود. شناسه عمومی که در پیش‌نمایش وارد می‌شود **به معنی اتصال حساب نیست**.

قبل از راه‌اندازی عمومی، سرور برتینا باید از نظر امکان اجرای زمان‌بند، ذخیره دائمی، HTTPS، نشست ادمین، PHP/Node و سازگاری اتصال خارجی تأیید شود. موتور فعلی در GitHub است؛ وجود کد با انتشار روی برتینا فرق دارد.

## مراحل هر شبکه

### اینستاگرام
1. حساب را در تنظیمات Instagram به Business یا Creator تبدیل کنید. برای مسیر Facebook Login، صفحه Facebook مرتبط و اختیارات مدیریتی لازم است.
2. برنامه Meta Developer با مجوز `instagram_content_publish` و سایر مجوزهای متناسب بسازید و تنظیمات App Review را تکمیل کنید.
3. در داشبورد نهایی «اتصال اینستاگرام» را بزنید؛ فقط در سایت Meta وارد شوید، حساب حرفه‌ای و مجوزها را تأیید کنید.
4. حساب و فرمت مجاز بررسی می‌شود؛ عکس/کاروسل/ریلز و استوری واجد شرایط به‌صورت جداگانه تست می‌شوند. استوری در Instagram API با Facebook Login برای حساب Business است، نه هر حساب.
5. لینک داخل کپشن معمولاً قابل کلیک نیست؛ لینک Bio یا استوری مجاز را برای دعوت به سایت تنظیم کنید.

### فیس‌بوک
1. از بخش توسعه‌دهندگان Meta، برنامه و مجوز انتشار Page را فعال کنید.
2. از طریق Facebook Login صفحه مدیریتی موردنظر را انتخاب کنید؛ کد و توکن فقط در سرور تبادل می‌شوند.
3. آزمایش یک پست لینک‌دار روی Page و دریافت شناسه واقعی پست. انتشار خودکار روی پروفایل شخصی را وعده ندهید.

### ایکس / توییتر
1. به `https://developer.x.com/` بروید؛ پروژه توسعه‌دهنده و هزینه/سقف درخواست‌ها را بررسی کنید.
2. مجوز User OAuth 2.0 با PKCE و `tweet.write` (و مجوزهای حداقلی لازم) را پیکربندی کنید.
3. پس از فعال شدن پنل خصوصی، با تأیید صفحه رسمی X اکانت را وصل کنید. هر حساب توکن و بودجه مستقل دارد.
4. پست نخست را با هدف محافظه‌کارانه حداکثر ۲۴۰ کاراکتر شامل هشتگ و لینک آزمایش کنید؛ شمارش واقعی لینک‌ها ممکن است قواعد اختصاصی X داشته باشد.

### تلگرام
1. با `@BotFather` ربات اختصاصی ایجاد کنید؛ توکن را هرگز در صفحه عمومی یا مخزن قرار ندهید.
2. ربات را مدیر کانال تبلیغاتی عمومی با اجازه ارسال پست کنید (کانال پشتیبانی خصوصی دانش‌آموزان جداست).
3. توکن و شناسه کانال را فقط در تنظیمات محرمانه سرور ثبت کنید؛ ابتدا یک پست آزمایشی و رسید `message_id` را بررسی کنید.
4. بعد از آن تصویر، آلبوم، ویدئو و محدودیت کپشن براساس Bot API جداگانه آزموده می‌شوند.

### ایتا
1. وارد `https://eitaayar.ir/` شوید و دسترسی برنامه ارسال را ایجاد کنید.
2. توکن برنامه و شناسه مقصد باید فقط در پیکربندی خصوصی سرور قرار بگیرند؛ مقصد باید مجوز لازم را به برنامه داده باشد.
3. مستند رسمی برنامک ایتا مسیر `POST https://eitaayar.ir/api/app/sendMessage` با JSON شامل `token`، `chat_id` و `text` و پاسخ موفق `ok:true, result:success` را نشان می‌دهد.
4. اجازه ارسال به **کانال** را مستقل از مثال کاربر تست می‌کنیم؛ تا زمانی که پاسخ واقعی کانال تأیید نشده، آداپتور را برای آن حساب عملیاتی اعلام نمی‌کنیم.
5. کانال تبلیغاتی عمومی از شناسه پشتیبانی ویژه دانش‌آموزان خریدار خدمات جدا باقی می‌ماند.

### آپارات
1. به `https://www.aparat.com/` بروید، وارد کانال خود شوید و مطابق راهنمای رسمی ویدئو بارگذاری کنید.
2. برای هر خبر متنی ابتدا محتوای ویدئویی دارای حق نشر ساخته شود؛ مقاله تنها مبنای متن توضیح، دعوت به مطالعه و لینک وب‌سایت است.
3. طبق راهنمای منتشرشده آپارات، برای ویدئو ۳ تا ۵ برچسب مرتبط و برای هر برچسب حداکثر ۲۳ کاراکتر درنظر گرفته شده است؛ قبل از هر ارسال واقعی محدودیت روز را دوباره بررسی کنید.
4. API عمومی و قابل اتکای بارگذاری خودکار برای حساب موردنظر هنوز مستقلاً تأیید نشده؛ دکمه «انتشار خودکار» تا زمان تأیید مجوز نباید فعال شود. در مرحله موقت، بسته ویدئو، کاور، عنوان، برچسب و توضیح برای بارگذاری دستی آماده می‌شود.

### واتس‌اپ بیزینس
1. حساب WhatsApp Business Platform در Meta Business و شماره کسب‌وکار را تأیید کنید.
2. برای پیام‌های آغازشده توسط کسب‌وکار از قالب تأییدشده و رضایت قابل اثبات مخاطب استفاده کنید.
3. امکان انتشار خودکار Status شخصی/بیزینسی را از API پیام‌رسانی نتیجه نگیرید. تبلیغات ناخواسته یا ارسال انبوه بدون رضایت ممنوع است.

### یوتیوب
1. پروژه Google Cloud و YouTube Data API را فعال کنید و تأیید OAuth را به کانال درست بدهید.
2. مجوز `https://www.googleapis.com/auth/youtube.upload` برای ارسال ویدئو لازم است.
3. ویدئوی واقعی همراه عنوان، توضیح، لینک سایت، کاور و برچسب آماده می‌شود. فقط پس از تأیید شناسه ویدئو و وضعیت پردازش، موفق گزارش شود.

### لینکدین
1. در `https://www.linkedin.com/developers/` برنامه بسازید.
2. مجوز `w_member_social` یا مجوز مناسب صفحه سازمانی را بگیرید.
3. ورود رسمی OAuth، انتخاب هویت و آزمایش پست تخصصی/دانشگاهی. نسخه‌گذاری API و تاریخ انقضای نسخه‌ها بررسی شود.

### شبکه‌های تکمیلی
Threads، Bluesky، Pinterest، TikTok، Mastodon، Discord و Google Business Profile هرکدام آداپتور مستقل دارند و فقط بعد از اعتبارسنجی مجوز، نوع رسانه، سقف پیام و قابلیت‌های جاری فعال می‌شوند؛ پرکردن فهرست با نام یک شبکه به معنی امکان انتشار نیست.

## روش ساخت پست

هر خروجی مستقل بر پایه URL و متن تأییدشده: عنوان واقعی → گزیده متناسب با مخاطب همان شبکه → حداکثر هدف طول متن → هشتگ‌های استخراج‌شده از واژگان موضوعی همان مقاله → CTA → لینک کامل اصلی با `utm_source` و `utm_campaign` → رسانه دارای مجوز → پیش‌نمایش و صف زمان‌بندی.

حدود طول در کد نسخه اول **اهداف تحریریه‌ای محافظه‌کارانه‌اند، نه ادعای سقف قطعی و به‌روز پلتفرم‌ها**. برای مثال هدف X برابر ۲۴۰، اینستاگرام ۱۵۰۰، تلگرام ۱۸۰۰ و ایتا ۱۷۰۰ کاراکتر در نسخه پیش‌نویس است. فرمت عکس/استوری/ویدئو محدودیت مستقل دارد و فقط بعد از بررسی مستند API و فایل واقعی امکان تأیید است.

## آزمون حساب‌به‌حساب

۱. شناسه عمومی مقصد را وارد کنید. ۲. اتصال مجاز و scopes را از سرور بررسی کنید. ۳. یک محتوای عمومی و مجاز انتخاب کنید. ۴. پیش‌نویس، هشتگ، لینک، رسانه، ساعت و مجوز را بازبینی کنید. ۵. یک ارسال آزمایشی مورد تأیید مالک انجام دهید. ۶. شناسه و URL پست را از ارائه‌دهنده دریافت و صحت فرمت را کنترل کنید. ۷. کلیک واقعی در آمار سایت را پس از ثبت داده رصد کنید. ۸. فقط آن حساب را فعال کنید. ۹. خطاهای نامطمئن بدون کنترل پست قبلی تکرار نشوند.

هیچ محتوای خصوصی دانش‌آموز/حامی، طرح منتشرنشده، قیمت تأییدنشده یا آدرس داخلی ویژه مشتری به موتور تبلیغات عمومی منتقل نمی‌شود.
