## Consolidating into a single folder WITHOUT breaking the site

`node platform/jrei/build-source-bundle.mjs` is a **future, explicitly invoked source-only export**. It finds the tracked JREI source and integration files in the canonical checkout, copies them into one self-contained *source archive directory* (retaining original relative paths), and writes a SHA-256 file inventory. The export deliberately does **not** copy private data, keys, downloaded model weights or untracked local files; it does **not** deploy, install, train or restart any process. A source archive cannot be treated as an independently executable hosted runtime without final dependency closure and acceptance.

**Source-of-truth principle:** leave each working file at its original path for now. Do not add manually maintained copies of the same runtime in this directory. When the independently deployable runtime has a reviewed import/dependency graph and a real restore/rollback rehearsal, migrate individual files behind compatibility facades with explicit acceptance evidence. This avoids breaking the JREI 8092 engine, the signed Ed25519 Windows queue, existing DB, frozen Bertina release workflow, SEO and commerce.
