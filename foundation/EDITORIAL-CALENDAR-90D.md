# Editorial metadata required for every article

- canonical URL
- primary intent
- audience
- author
- reviewer when high-stakes
- date published
- date modified
- last reviewed
- title/meta
- one H1
- image + alt + dimensions + provenance
- internal links
- relevant service link
- schema
- index state
- source/evidence notes
- annual-data verification state

---

# Content quality gates

An article does not publish if:
- it repeats an existing page without adding a distinct intent;
- it has no meaningful answer beyond a CTA;
- its annual data are not verified;
- it needs an image but none is ready;
- it contains confidential pre-publication concepts;
- it overclaims scientific certainty;
- it has no internal-link role in the ecosystem.

---

# Conversion principle

Content is not written merely to attract clicks.

**Article → understanding → relevant service/tool → informed action**

The CTA must follow the informational task. It must not interrupt or manipulate it.
