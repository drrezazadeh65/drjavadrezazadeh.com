# RAVE priority roadmap — revenue-first, evidence-first

## P0 — immediate
- Run read-only audits of robots.txt, llms.txt, sitemap index, Persian, English and services sitemaps.
- Verify indexability, canonical/hreflang and sitemap integrity using existing site CI; do not rewrite existing manifests.
- Map each indexed educational guide to the most relevant verified service, without forced links or unverified claims.
- Establish Google Search Console and Bing Webmaster **read-only** adapters once authorized; report impressions, clicks, CTR, coverage and conversion by landing page.
- Verify public Person/Organization structured data, authoritative profile citations and AI search bot access without promising AI rankings.
- Define opt-in, consent-safe attribution and revenue conversion events; avoid putting customer PII in GitHub.

## P1 — after P0 evidence
- Search query opportunity clustering; editorial briefs for underperforming pages.
- AI answer visibility sampling with prompt logs, citation evidence and reproducible method.
- Earned editorial mentions and outreach drafts; no paid/manipulative backlink schemes.
- Approved social distribution queue; first API integrations chosen by verified audience impact.

## P2 — incremental
- Expand official adapters for social networks in channel registry.
- Campaign experimentation, multi-touch attribution, editorial outreach, qualified lead nurturing and sales forecasting.
- Dashboard and secured backend for private operational metrics.

## Release criteria
Every module has an owner, source provenance, tests, policy permissions, measured outcome, rollback and portability review. GitHub is source of truth; Pages is replaceable; Workers optional only.
